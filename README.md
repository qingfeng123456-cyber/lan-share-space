# 局域网共享空间

一个基于 [copyparty](https://github.com/9001/copyparty) 的中文网页文件共享工具。将一台 Windows 电脑作为主机，其他设备可以通过局域网浏览器查看、上传、下载、重命名和删除共享文件。

仓库已经包含 copyparty 和 Windows 64 位便携 Python，**不需要再单独下载 copyparty 或安装 Python**。文件保存在主机上，速度取决于网络和磁盘。

## Windows 使用步骤

1. 打开本仓库，点击右上角 **Code → Download ZIP**。下载完成后，右键 ZIP 文件选择“全部解压缩”。
2. 打开解压后的文件夹，双击 **双击启动.cmd**。首次运行会自动解压仓库附带的 Python 运行环境，不需要修改系统 Python 或 PATH。
3. 在启动窗口中指定要共享的文件夹。直接按 Enter 可以使用程序旁边的 `共享文件` 文件夹；如果它不存在，按提示确认创建。也可以输入已有文件夹的完整路径。
4. 选择访问范围：输入 **1** 仅供本机测试；输入 **2** 供局域网访问。选择局域网时，继续输入网络地址列表中的序号，选择连接家里或办公室网络的网卡。
5. 启动后浏览器会自动打开；窗口也会显示访问地址，例如 `http://主机IP:3923/`。在其他同一局域网设备的浏览器中输入窗口显示的实际地址，即可打开共享页面。
6. 保持主机开机、不休眠，并保持启动窗口打开。停止共享时，在窗口按 **Ctrl+C** 或关闭窗口。

## 访问范围与文件权限

- 选择局域网模式后，**所有能够连接该地址的人都可以不登录查看、上传、修改和删除共享目录中的文件**。请使用可信网络和专用共享目录，并单独备份重要文件。
- 这里使用 HTTP，传输内容不加密；请不要把服务端口映射到公网。
- 默认端口为 3923。若提示端口被占用，先关闭此前启动的共享程序，再重试。
- 原版 SFX 未额外打包 Pillow、Mutagen 等可选组件；文件共享功能不依赖它们，部分媒体缩略图或元数据功能可能受限。

## 找不到或打不开页面？

- **本机可以打开，其他设备打不开**：确认其他设备和主机在可互通的网络中，输入的是启动窗口显示的主机地址，而非 `127.0.0.1`。访客网络和设备隔离可能阻止互访；还要检查 Windows 防火墙是否允许所用端口在专用网络入站。
- **无法上传或删除**：检查 Windows 中共享文件夹的读写权限，以及主机磁盘剩余空间。
- **提示缺少文件**：请重新完整下载并解压 ZIP，保持目录里的文件放在一起，不要直接双击压缩包内的文件运行。
- **上传进度中断**：重新选择同一个文件，可通过普通“上传文件”入口继续上传。
